## SSD 存储在 VPS 中究竟改变了什么？

它消除了磁盘瓶颈。在传统的 HDD 后端 VPS 上，硬盘的随机读取 IOPS 大约为 100–200。SSD 改变了服务器执行的每一次小规模、零散读写的物理特性。

在关键指标上，SATA SSD 与 NVMe SSD 的对比：

| 指标 | SATA SSD | NVMe SSD |
| --- | --- | --- |
| 顺序读取 | ~550 MB/s | 3,500+ MB/s |
| 随机 4K 读取 IOPS | ~80,000 | 500,000+ |
| 延迟 | ~100 µs | <20 µs |
| 接口 | SATA III | PCIe 直连 |

这种差距何时显现？如果你运行的是静态网站，可能几乎察觉不到。任何执行大量小规模、分散读写操作的任务——数据库、邮件服务器、频繁写入的日志、电商结账流程——都能直接从查询时间上感受到这种差距。NVMe 的优势源于 PCIe 直连，这绕过了旧版 SATA 接口强加的延迟和带宽限制。

一个与速度同样重要的注意事项：原始 IOPS 在驱动器发生故障时毫无意义。任何值得考虑的服务商都会在阵列中镜像数据（RAID10 是标准配置），因此在比较时，请像询问原始速度一样询问冗余方案。
